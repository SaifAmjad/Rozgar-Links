# Milestone 5 QA

## Automated coverage

- Shared schemas reject sample listings with external URLs or false source labels and require HTTPS URLs for authorized records.
- Provider tests verify exactly 40 fictional samples, all six GCC countries, all 12 taxonomy fields, unique IDs, `isSample: true`, `source: "Sample listing"` and null source URLs.
- Repository tests cover validated atomic writes, concurrent saves, temp-file cleanup and in-memory fallback after malformed cache data.
- Service tests cover case-insensitive search, exact country/field filters, stable ordering, pagination, stale fallback and total provider failure.
- API tests cover valid envelopes, bounded pagination, bad countries/fields/query values and safe `400`/`503` responses.
- Client tests cover visible sample provenance, no original link for samples, safe attributes for authorized links, validated application query values, filters, pagination, stale notices and featured samples.

## Source and cache behavior

- `ManualProvider` is the only active provider and reads committed `server/data/jobs.seed.json`.
- Every company name is explicitly fictional and every current card displays “Sample listing”; no invented GulfTalent or NaukriGulf source URLs exist.
- Runtime data is atomically written to ignored `server/data/jobs.cache.json` and refreshed at most daily during requests plus a single scheduled refresh at `00:15` in the configured timezone.
- Provider failure preserves the last validated cache and labels it stale. With no usable cache, the API returns a safe `503` response.
- `ScraperProvider` is a throwing stub. `ENABLE_SCRAPING` accepts only `false`, so scraping cannot be activated without a future reviewed implementation change.

## Review notes

- Jobs cards remain keyboard accessible and expose company, location, taxonomy field, source and sample status without relying on color alone.
- Search, selects and pagination use native controls with visible labels and focus states; the mobile-first grids expand at existing breakpoints.
- Browser Lighthouse measurement and full 320/768/1440 manual verification remain part of the M8 deployment gate.
