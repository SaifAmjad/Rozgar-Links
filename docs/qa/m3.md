# Milestone 3 QA

Date: 2026-10-13

## Taxonomy coverage

- Validates the 12 required fields, semantic version, kebab-case IDs and non-empty labels.
- Validates 8–15 genuine roles plus one consistently labelled `other` role per field.
- Rejects duplicate field and role IDs; preserves stable IDs in an additive-role fixture.
- Uses the same parsed catalog for API responses and application field-to-role validation.

## Application contract coverage

- Tests 17/18 age boundaries and six-calendar-month passport validity, including month-end.
- Tests Pakistani CNIC format without imposing that format on other nationalities.
- Tests unknown fields, mismatched roles and required Other-role text.
- Tests salary ordering/currency, future payment date, driving-licence country and all consents.
- Tests `All Gulf` expansion, deduplication and required numeric input behavior.

## API coverage

- `GET /api/taxonomy` returns a response accepted by the shared taxonomy schema.
- `GET /api/config/public` returns strict demo-only display values and no SMTP/private keys.
- Public config and taxonomy endpoints expose the same taxonomy version.
