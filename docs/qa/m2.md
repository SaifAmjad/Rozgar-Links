# Milestone 2 QA

Date: 2026-10-13

## Automated coverage

- Route rendering for home, jobs, apply, FAQ, contact, privacy, terms, fees/refunds and 404.
- Mobile navigation open state, `aria-expanded`, Escape close behavior and focus return.
- Independent-service disclaimer, licence placeholder and legal navigation visibility.
- Input label, description, required state, invalid state and error association.
- Reduced-motion behavior is included in the global stylesheet.

## Responsive review

- Headless Chrome captures reviewed at 500px mobile, 768px tablet and 1440px desktop widths.
- Windows Chrome enforces an approximately 500px minimum headless window; the 320px layout was
  reviewed from responsive source constraints with no fixed page minimum width.
- Mobile navigation, stacked calls to action, card reflow and desktop navigation were verified.
